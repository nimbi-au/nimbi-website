# nimbi — brand asset pack

Typeface: **Bitter ExtraBold (800)** — included in `font/` (SIL Open Font License).
All logo text is converted to outlines, so no font install is needed to use the SVGs.

## Structure
- `svg/logo/` — full wordmark SVGs (colour, white-bg, black-bg, primary-bg, mono charcoal/white)
- `svg/monogram/` — "n" mark SVGs (colour, white-bg, black-bg, mono charcoal/white)
- `svg/icon/` — app/social rounded-square icons (full colour, dark, white, dark-bg)
- `png/` — ready-to-use PNG exports (transparent + on-background, plus icon sizes 1024/512/180/64 and favicon.ico)
- `svg/colour-palette.svg` + `colour-palette.png` — palette reference card
- `font/` — Bitter ExtraBold TTF + licence

## Usage notes
- Always use the provided logo files; don't recreate or alter the logo.
- Maintain clear space equal to the height of the "n" around the logo.
- Use the full-colour logo on light backgrounds and the white logo on dark backgrounds.
